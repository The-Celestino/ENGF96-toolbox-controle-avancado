# Materiais comuns — identificação de sistemas

O arquivo `identificacao_sistemas.rar` foi fornecido com os materiais da disciplina. Seu conteúdo está extraído em `arquivos_originais/`, mantendo os nomes e os bytes dos arquivos MATLAB/Simulink, inclusive cópias de versões anteriores.

Os quatro scripts adicionais de estimação enviados estão em [exemplos_estimacao/](arquivos_originais/exemplos_estimacao/). São exemplos do fluxo de aquisição, ajuste e comparação de modelos; não contêm as séries temporais dos ensaios. A toolbox mantém aquisição, seleção e validação final em dados distintos.

## Origem e créditos

Material de aula fornecido pelo usuário. A autoria, os créditos e os avisos de direitos autorais dos arquivos originais foram preservados. Estes arquivos são referências de estudo e não integram a licença do código Python da toolbox.
